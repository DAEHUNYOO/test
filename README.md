## 카피바라 먹이 탐험 (`capybara-game/index.html`)

핸드폰 브라우저에서 바로 할 수 있는 2D 횡스크롤 게임입니다. 설치 없이 HTML 파일 하나로 동작합니다.

- **◀ ▶** 이동, **▼** 발판에서 내려가기, **▲ / 점프** 뛰어오르기(길게 누르면 더 높이)
- **물기**: 앞을 물어요. 사자는 세 번 물면 쫓아낼 수 있어요 (+100점)
- 사자가 웅크리고 `!`가 뜨면 곧 덤벼들어요. 부딪히면 하트가 하나 줄어요
- 먹이(풀·귤·옥수수·수박)를 먹으면 점수, 사과는 하트 회복, 연못(온천)에 있으면 체력이 천천히 회복
- **우정 방울**: 다가가면 친구 카피바라가 와서 30초 동안 함께 사자를 물어요 (최대 2마리, 친구도 3번 맞으면 돌아가요)
- 먹이 8개마다 레벨이 오르고 사자가 늘어나요
- PC 키보드: 방향키 이동 · Space 점프 · X 물기 · P 일시정지

### 핸드폰에 앱처럼 설치하기 (APK 없이)

웹 앱(PWA)이라 앱 스토어나 APK 없이 설치됩니다. 한 번 열고 나면 인터넷 없이도 실행돼요.

1. 저장소 Settings → Pages에서 브랜치를 선택해 GitHub Pages를 켭니다.
2. 핸드폰에서 `https://<사용자>.github.io/test/capybara-game/` 를 엽니다.
3. 홈 화면에 추가합니다.
   - 안드로이드(Chrome): 메뉴 ⋮ → **홈 화면에 추가** (또는 **앱 설치**)
   - 아이폰(Safari): 공유 버튼 → **홈 화면에 추가**
4. 홈 화면의 카피바라 아이콘을 누르면 주소창 없이 전체 화면 가로 모드로 실행됩니다.
